# MCP Tools for BIBAS CRM

Эта папка содержит описания инструментов (tools) для MCP-сервера, который будет взаимодействовать с CRM ювелирной мастерской BIBAS.

## Структура

- `tools.json` — манифест всех доступных инструментов для агента.
- `stubs/` (будет позже) — Python-заглушки и view-функции для API-эндпоинтов, которые используют инструменты.
- `examples/` (будет позже) — примеры запросов и ответов для отладки.

## Как добавлять новый инструмент

1. Опиши инструмент в `tools.json` (имя, описание, входные/выходные параметры).
2. Реализуй соответствующий API-эндпоинт в Django (например, `/api/v1/agent/...`).
3. Обнови документацию в этом файле, если поведение нетривиальное.

## Health check

Инструмент `health_check` соответствует публичному GET-эндпоинту
`/api/v1/agent/health/`. Поле `endpoint` в [tools.json](./tools.json) фиксирует
это соответствие как локальное соглашение проекта; MCP-сервер пока не подключён.
Входные параметры передаются в query string: `?verbose=true` или `?verbose=false`
(по умолчанию `false`). Другие значения возвращают HTTP 400, методы кроме GET — HTTP 405.

Это заглушка: `status: "ok"` подтверждает только доступность HTTP-обработчика.
Реальные проверки БД и очереди задач пока не выполняются. При `verbose=true`
поле `services` содержит `database: "not_checked"` и `task_queue: "not_checked"`;
иначе оно пустое. Поле `metrics` пока всегда пустое. Данные CRM не возвращаются.
